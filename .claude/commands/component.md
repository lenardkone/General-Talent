# UI Component Builder

Build a polished, reusable UI component. 

## Process
1. Identify the component type and its variants (size, state, style)
2. Define the props/API surface (keep it minimal)
3. Implement with clean markup and styles
4. Include all interactive states: default, hover, focus, active, disabled, loading
5. Make it accessible (ARIA roles, keyboard navigation, screen reader text)

## Component types I excel at
- Buttons (primary, secondary, ghost, icon, loading)
- Forms (inputs, selects, checkboxes, toggles, validation states)
- Cards (content, product, stat, profile)
- Navigation (navbar, sidebar, tabs, breadcrumbs)
- Modals & drawers
- Tables & data grids
- Badges, chips, tags
- Alerts & toasts
- Avatars & media
- Skeletons / loading states

## Output
Provide the complete component code. If it's React, include TypeScript types. If it's plain HTML/CSS, make it copy-paste ready.
