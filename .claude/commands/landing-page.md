# Landing Page Builder

Design and build a complete, conversion-focused landing page.

## Sections to include (adapt as needed)
1. **Hero** — headline, subheadline, CTA button, optional image/visual
2. **Social proof** — logos, testimonials, or stats
3. **Features/Benefits** — 3–6 cards or rows explaining the value
4. **How it works** — numbered steps or timeline
5. **Pricing** (if applicable) — clear tiers with feature lists
6. **FAQ** — accordion-style
7. **Final CTA** — strong closing section
8. **Footer** — links, legal, social

## Design principles
- Above the fold: clear value proposition within 5 seconds
- One primary CTA per section (no competing actions)
- Use visual hierarchy to guide the eye down the page
- Trust signals: testimonials, logos, numbers
- Fast and lightweight — no unnecessary JS

## Output
Complete HTML file with embedded CSS (or Tailwind). Mobile responsive. Ready to open in a browser.
